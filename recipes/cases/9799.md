- **Files:** `/Volumes/Photos2/root/2026/2026-11-01/_52_9799.CR3` (47 mm, f/11, 1/125, ISO 200, 8192×5464) → saved `_52_9799-Edit.tif`, 1.05 GB, same folder. A different `_52_9799.CR3` also exists in `2026-05-09`: check the path before reading EXIF.
- **Baseline:** rock hue 52.9° (no raw-SO change), no sky, p99.9 72.2, median 32.1 (3:2). 16:9 control: median 32.6, p5 8.8, p95 57.5, p99.9 72.5, weight Mid-Center 13.0 / Mid-Right 11.8%.
- **Crop:** 16:9, `delete:false`, top 856 px dropped (layer bounds top −856). A 4:3 crop left a thin foreground wall at the left that looked out of place (tried twice); 16:9 was more balanced and gave the vignette something to hold.
- **Masks (all user-made, after the crop and the critique):** object masks for the central spires (5), the pale cliff (2), the left massif (1, left untouched) and a right slope (2). Select Landscape → Vegetation did not pick up the trees, so the user used **Color Range ∩ radial** for the pines (center, and a second one for the top-right corner trees) and for the right corner cliff texture.
- **Final filter (stored; dialog = ×100, Exposure ×4):**
  - Center cliff (spires): Exp +0.06, Highlights −0.08, Clarity +0.15, Texture +0.15.
  - Right cliff (pale cliff): Exp **+0.04** (lowered from +0.06 so it does not rival the spires), Highlights −0.12, Clarity +0.12, Texture +0.12. Right corner cliff: Clarity +0.05, Texture +0.08. Right slope: Exp −0.0625 (separation).
  - Trees (Color Range ∩ radial, box L 0.18 R 0.62 T 0.22 B 0.66, feather 60): Exp +0.16, Shadows +0.20, Sat +0.05, Texture +0.10. Right trees (radial ∩ Color Range, upper right): Exp +0.08, Shadows +0.10, Sat +0.03, Texture +0.05 (about half the center).
  - Vignette: one inverted radial, box L −0.13 R 1.27 T 0.14 B 1.18, feather 60, Exp −0.05.
  - **Calibration in the filter (user): Blue Hue −8, Saturation +7** (+10 first; pulled back after the 1:1 look).
- **Result vs the 16:9 control (2000 px):** spires/Mid-Center +2.4 L\*, detail +14.6%, weight 13.0 → 15.9%; Mid-Right +1.6 (weight 11.8 → 13.6%); Bot-Center +2.6, detail +19%; pines +3.0 L\*; corners −0.5…−1.7 L\* (vignette; Top-Left −1.7); Deep darks +0.7, Shadows +0.1, Midtones +0.2; C\* +1…+2 on the rock (about +6% from the calibration, global); p99.9 72.5 → 75.0, no clipping, median 32.6.
- **What worked:**
  - Crop → critique → user masks → plan order: every correction had a mask the user had judged first; the pines lift stayed in the valley (rock beside the pines −0.5, outside the radial −3.1 = vignette only), so the Color Range ∩ radial intersect works.
  - The 1:1 hard-cropped checks (spire tips/pine edge; right cliff with stacked Clarity/Texture) were clean: no halos, no crunch, strata keep their gradation.
  - Noise: ISO 200, no visible noise even at +3× lifted shadows at 1:1 → no denoise.
  - The user's own passes (pale cliff, right trees, right slope, vignette strength, Calibration) were checked with region numbers each time.
- **What went wrong / lessons:**
  - I read the EXIF from a same-named CR3 in another folder (ISO 500) and told the user the file was ISO 500; the correct file is ISO 200. Verified path first from now on.
  - A hard-crop in the same batch as `duplicate` silently did not run (the copy stayed 8192×4608): send `crop` as its own call and check the size.
  - Rendering a 8-bit PNG, I divided by 257 as if it were 16-bit and got a black preview; check the dtype.
  - A parallel `save` + `close` closed the duplicate when the save had failed on a parameter name (`file_path`, `file_type`).
  - Vignette forecast −2…−3 L\* corners; the large feathered ellipse gave −1.4 (final −0.5…−1.7 with the right-corner masks).
- **Not checked:** print; whether the saved TIFF equals the last render (the user saved after pass 4 and reported no change); no calibration-off control (the calibration effect was estimated from unmasked cells).
