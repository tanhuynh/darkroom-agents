# Lens Blur adds `$Lblr`, `$DMIn` and depth corrections to the filter; scripted writes must resend them
- **Agent:** claude
- **Target:** engine.md §5 (Read / Edit in place) and §6 (mask schema)
- **Type:** engine fact
- **Rule:** IF the Camera Raw Filter contains a Lens Blur (the user ran it in the dialog) → `get smartObject` returns two extra filter keys, `$Lblr` (`crs:LensBlur`: `Active`, `BlurAmount`, `FocalRange`, `SubjectRange`, `SampledArea`, `HighlightsThreshold/Boost`, bokeh shape…) and `$DMIn` (`crs:DepthMapInfo`: digests of the cached depth tables), and `$LCs` gains a `crs:DepthBasedCorrections` list next to `MaskGroupBasedCorrections` (corrections with only `LocalCorrectedDepth` = ±1 and `Mask/Aggregate` → `Mask/Paint` dabs = the user's depth refinement strokes). DO resend `$Lblr` and `$DMIn` with every scripted write (keys not sent are reset), keep `DepthBasedCorrections` untouched, omit `$BigT` → CHECK `get` shows both keys and the depth corrections after the write, and a diff render against the unchanged re-render shows only the intended change.
- **Evidence:** case 0025, after the user's Lens Blur (BlurAmount 50, Highlights Threshold/Boost 50):
  - `$LCs` grew from ~12 KB to 48 KB; `$BigT` ~9.7 MB.
  - Pre-blur tonal corrections (Pull, Pull Copy, Push, Background, …) rendered identically (≤ 0.05 L\*, ≤ 0.03 b\*) against an unblurred control; local detail in the blurred upper background fell 32–83%.
  - Reopening the dialog for the blur recomputed the Select Subject mask (digests and Origin 156,403 → 203,411); bird tone moved ≤ 0.3 L\*.
  - **Verified on a saved copy (`_52_0025-2-Edit-1.tif`):** (1) identity write — every key resent unchanged, `$BigT` omitted: `DepthBasedCorrections` block (4 corrections, 17 `Mask/Paint`), `$Lblr`, `$DMIn` byte-identical on readback; render vs unchanged control max |ΔL\*| 0.26, mean 0.07, detail ±0.4% in every 3×3 cell (a small uniform +0.08 L\* in the top cells, cause unknown, imperceptible). (2) tonal write (Pull `CorrectionActive` false, Pull Copy Exposure −0.10 → −0.06): same keys preserved, blurred upper background detail unchanged (0.0%), bottom +3.2 / +2.0 / +0.9 L\* exactly as in the earlier unblurred pass. So depth strokes survive scripted writes in `$LCs` — unlike standalone Brush masks on 0044 — **provided** `$Lblr`, `$DMIn` and the whole `DepthBasedCorrections` block are resent; hand-painted strokes live in the XMP, not only in `$BigT`. Not tested: editing inside the depth block itself, a write that omits `$Lblr`/`$DMIn`.
- **Also seen (process):** a Photoshop out-of-memory crash and restart restored the document one pass behind (my last two scripted edits — a CorrectionActive flag and an Exposure value — were lost; the document `_id` changed 488 → 59 and its path changed folder). After any restart, read the live filter and compare with the last written XMP before assuming state.
- **Conflicts with:** none. Extends engine.md §5 "Edit in place — resend EVERY key" with the two Lens Blur keys.
- **Scope:** seen on 1 case (0025).
